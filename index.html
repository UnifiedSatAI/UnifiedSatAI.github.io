Unified Deep Learning Benchmark
for Satellite Image Restoration and Generation

Introduction

Deep learning methods for satellite image restoration have advanced rapidly across multiple tasks such as cloud removal and super-resolution. However, their evaluation remains fragmented, as existing benchmarks are typically task-specific and rely on different datasets, preprocessing pipelines, and metric implementations. This fragmentation makes results harder to reproduce and can make model comparison less transparent.

To address this problem, this project presents a modular, reproducible, and scalable benchmarking pipeline for satellite image restoration. The framework integrates dataset loading, preprocessing, model execution, metric computation, visualization, and experiment logging into a single unified evaluation workflow. By bringing all these components together, the system enables fair and consistent evaluation across different restoration tasks and models.

The current implementation supports two representative restoration settings: cloud removal using the AllClear dataset and super-resolution using PROBA-V SR. The framework is designed to be extensible, allowing for future integration of additional datasets and restoration tasks while maintaining a shared evaluation structure.

The main goal of this project is to support clearer model comparison, easier integration of new methods, and more transparent experimental reporting. By providing a shared evaluation structure, the framework helps reduce methodological inconsistency across restoration tasks and offers a practical foundation for future benchmarking research in remote sensing and satellite image processing.

Project Overview

The Unified Deep Learning Benchmark for Satellite Image Restoration is a modular, reproducible, and scalable benchmarking pipeline designed to organize the main stages of satellite image restoration evaluation into a single structured workflow. The framework integrates dataset loading, preprocessing, model execution, metric computation, visualization, and experiment logging into a unified evaluation process.

The framework follows a sequential evaluation pipeline: First, a task-specific dataset loader reads the selected benchmark data. Second, preprocessing prepares the input data for the selected model. Third, the model is executed through a shared inference interface. Fourth, the prediction is compared with the reference target using predefined metrics. Finally, the framework stores metric values, visual outputs, and configuration records together, enabling reproducible experiments.

A key design feature separates shared evaluation components from task-specific components. Shared components include metric computation, logging, visualization, and output organization. Task-specific components include dataset loading, input preparation, model adapters, and restoration targets. This separation allows the framework to remain reusable while still respecting the differences between different restoration tasks.

The current implementation supports two representative restoration settings: cloud removal using AllClear and super-resolution using PROBA-V SR. The framework evaluates predictions using well-known reconstruction-oriented metrics including Peak Signal-to-Noise Ratio (PSNR), Structural Similarity Index Measure (SSIM), Spectral Angle Mapper (SAM), Erreur Relative Globale Adimensionnelle de Synthese (ERGAS), and Learned Perceptual Image Patch Similarity (LPIPS). The framework is designed to be extended through modular loaders, model adapters, metric functions, and visualization modules, making it suitable for gradual expansion to support additional datasets and restoration tasks.

Datasets Used in Benchmark

Our framework integrates the following public satellite datasets for comprehensive evaluation across different tasks and image types.

AllClear

Cloud removal dataset with paired cloudy and cloud-free satellite images for evaluating cloud removal algorithms.

SEN12MS-CR-TS

Sentinel-2 multi-spectral cloud removal time series dataset for temporal consistency evaluation.

WorldStrat

Global stratified satellite imagery dataset for diverse geographic and seasonal representation.

PROBA-V SR

Super-resolution dataset from PROBA-V satellite for evaluating high-resolution image generation.

SAT25K

Large-scale satellite image dataset with diverse resolutions and processing tasks.
